# Week 4 — Final Stakeholder Report

## Objective
Build an end-to-end data analysis workflow that converts raw business data into actionable insights.

## Methodology
1. Clean duplicate and missing records.
2. Explore distributions, trends and segment performance.
3. Aggregate revenue by category, region and department.
4. Build a baseline Linear Regression model for sales prediction.
5. Present KPIs and trends through a Power BI dashboard.

## Key metrics
The final numeric values must be generated from the actual project dataset. They are intentionally not fabricated because the Week 4 ZIP contains assignment PDFs but not the dataset itself.

## Recommendations
- Focus resources on segments with sustained high revenue and healthy profitability.
- Investigate underperforming categories and regions using product mix, pricing and demand indicators.
- Use time-series trends for inventory and marketing planning.
- Monitor Average Order Value alongside total revenue.
- Treat the regression as a baseline and test tree-based models after establishing clean, leakage-free features.

## Reproducibility
Run `capstone_solution.py` with the actual CSV/XLSX dataset. It generates cleaned data, EDA summaries, segment revenue files, regression metrics and an actual-vs-predicted chart.
