# Week 1 — Excel & Data Fundamentals

Solved Week 1 practice set and project guidance based on the uploaded Week 1 material.

## Files
- `practice_set_solutions.md` — point-wise solutions for all 5 practice questions plus dashboard configuration.
- `week1_solution.py` — reproducible Python solution for cleaning and generating the requested summaries.
- `sample_sales_data.csv` — small demonstration dataset for testing the script.

## Dataset note
The supplied `week 1.1.pdf` contains a link to the Global Superstore 2016 dataset, but the uploaded ZIP contains only the three PDFs and not the dataset file. The solution therefore avoids inventing final numeric results from an unavailable dataset. Replace `sample_sales_data.csv` with the linked dataset when running the script for the actual figures.

## Run
```bash
python week1_solution.py sample_sales_data.csv
```
