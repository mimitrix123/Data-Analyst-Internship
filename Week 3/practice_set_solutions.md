# Week 3 — Python & Data Wrangling

## Complete Solution

1. **Load and inspect:** use `pd.read_csv()`, `head()`, `shape`, `info()`, and `isna().sum()`.
2. **Clean:** remove duplicates; fill numeric missing values with the median and categorical missing values with `Unknown`.
3. **Filter:** retain meaningful records, e.g. positive Sales/Revenue.
4. **Create columns:** calculate derived metrics such as `Calculated_Revenue = Quantity × Unit Price` when those fields exist.
5. **Visualize:** use Matplotlib for distributions and category/time summaries. Seaborn may be used for heatmaps or categorical plots.
6. **Save:** export the cleaned and filtered datasets so the work is reproducible.

See `solution.py` for executable code.
